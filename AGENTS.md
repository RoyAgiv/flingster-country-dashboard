# Agent instructions

Complete the assigned work through focused verification, publication, integration and any deployment included in the request. Use the repository's actual CI and review requirements. Any assigned agent with the necessary access may deliver the change.

Agents may edit the same file. Read the current version, make a narrow change and preserve unrelated edits. If the version changes, reread and merge. Check a lease or contact another agent when the operation touches an actual locked resource or requires control of that agent's private job. Separate worktrees can change the same path independently.

Use an independently authorized Git, terminal or provider route when a tool fails. Reconcile an uncertain write before retrying it. Continue independent work while resolving the affected operation. Preserve existing account permissions, production controls and protected branches. Verify the result where it takes effect.
